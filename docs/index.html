The core idea

An autoregressive model outputs a probability for every sample it sees. That single property gives two products from one trained model.

🔍 Label-free anomaly detection

Samples the model finds improbable (high negative log-likelihood) are anomalies — with no labeled failure data, which is exactly what the predictive-maintenance market is stuck on.

🗜️ Neural compression

The same per-sample probabilities drive an arithmetic coder. “Predict the next sample well” is mathematically identical to “send fewer bits” — a directly billable saving on the wire.

How it works

One streaming, causal model feeds three heads — the same computation runs bit-for-bit on an MCU.

Raw 1-D signal→ µ-law quantize→ WaveNet-lite (INT8, causal)→ P(next | past)
Likelihood → anomaly score Entropy coder → compressed bits Sampler → synthetic / infill

Why it's worth money

Fewer bytes on cellular/satellite/LoRa links, no rare failure labels needed, and it runs offline on cheap MCUs — privacy, battery life, and bandwidth savings in one model.
